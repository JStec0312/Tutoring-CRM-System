# TDE secret examples

The passwords in this directory are examples only. Create `.secrets/` with unique passwords in files of the same names and provide the matching `TutoringTdeCert.cer` and `TutoringTdeCert.pvk` certificate backup files. The application does not generate these files. Never use or commit real credentials or private keys here. See [TDE documentation](../docs/data_security/tde.md).
